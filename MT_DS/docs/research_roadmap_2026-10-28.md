**1. 主线与 E4 对照的关系**

主线继续采用：MT_DS → 解码器边界读出/反馈 → 指定编码器跳跃分支的贡献评价 → 训练中真实干预校准 → 可靠的有无标签交互。

此前将“旧 E4 辅助分支整体迁移”放在第一优先的建议需要修正。它适合回答旧分支对当前 Baseline 的兼容性，却不是解码器反馈驱动 skip 交互的必要前置条件。旧结果值得保留为正向历史证据；旧 E4 探针作为补充对照，不作为当前主线的默认起点。

本次优先级调整基于研究问题，而非新证据已经证明 D3 优于 E4。当前没有公平的位置消融，不能下这种结论。

边界监督的位置与被评价/交互的特征位置是两个问题：监督位于解码器预测头，评价和交互位于编码器传入解码器的 skip。它们可以同时成立。

| 组成 | 本轮起点 | 后续扩展 |
|---|---|---|
| 原分割深度监督 | 原四尺度 CE+Dice，全部保留 | 只有论证 DS 作用时再匹配消融 |
| 边界读出头 | D3/half 融合特征，1/2、32ch | D2/quarter，1/4、64ch |
| 归因对象 | E2→D3 这条 skip 边 | E3→D2；必要时 E4→D1 |
| 交互位置 | Student 的同一 skip 边 | 有证据后再多尺度 |
| Teacher | 干净、stop-gradient 的目标与可靠性来源 | 不做特征交换 |
| 旧 E4 probe | 可选支线 | 不与匹配的位置消融混淆 |

**2. 当前结果能支撑的判断**

窄带0.03与独立边界头0.03均没有在 LA/Pancreas 建立稳定整体收益。胰腺存在表面距离与Dice的取舍、独立头的部分中期收益；不能概括为所有时点全面恶化。

边界 loss 有效参与优化、训练 loss 下降，但当前未记录可验证的 skip 贡献及实际注入收益。现有两处卷积参数探针不是激活/分支归因。旧 probe 的在线遮挡只证明辅助头依赖高分通道，未重算主 decoder，不能替代当前机制实验。

因此下一轮应从“继续找一个能涨Dice的边界损失”转向两项明确检验：边界反馈能否评价实际 skip 干预；把边界训练梯度加给骨干是否确有必要。完整方法最终仍须证明分割收益，不能以辅助任务拟合替代。

结果证据见[完整复核](boundary_results_review_2026-10-28.md)；旧实现与新旧差异见[对照分析](boundary_supervision_comparison_2026-10-28.md)。

**3. 下一轮共同设置：单个 D3 边界头与真实 skip 门**

保留原四尺度分割、原 soft MSE、Teacher EMA/BN、病例划分、patch、增强、SGD、LR和训练预算。只保留当前独立头实现的 half 读出位置，暂不加入 full 辅助头：

`H_D3 = upsampled_decoder + E2_skip`，取自现有 `out_conv_2` 的输入。

边界头沿用 `Conv3(32,32) → ReLU → Conv1(32,1)`，不新增BN/Dropout；GT仍为完整标注体积生成的2 voxel双侧带，原生half尺度用面积覆盖率标签；有效样本、正类权重、BCE+Dice定义保持现有版本。不同时更换目标、BN、位置和无标签损失。

选 D3 是为了把问题缩到一个位置并与实际 skip 操作对齐，不是认为它已被证明最优。已有最终卷积梯度方向差异支持单独研究 full 头，但不足以证明 full 是退化根因。

在相加处引入逐样本、逐通道的诊断门：

\[
H_c=U_c+g_cE_{2,c},\qquad g_c\equiv1.
\]

门不是可学习参数，不进入优化器。E2继续通向更深编码器的路径不改动，只门控其skip副本，以免总编码器梯度与真实修改路径不一致。

**4. 下一轮建议的两种条件，共四次完整训练**

命名只是候选标识，不代表目录已经创建或任务已启动。

| 条件 | 边界头学习 | 边界训练梯度是否更新骨干 | 在线skip评分/校准 | LA10% | Pancreas10% |
|---|---|---|---|---|---|
| M0：D3读出对照 | 是 | 否，训练头时detach其输入 | 是 | 从头15000步 | 从头15000步 |
| M1：D3联合监督 | 是 | 是 | 是 | 从头15000步 | 从头15000步 |

两组都不交换通道、不加Bank、不加额外无标签边界优化项。原seed42 Baseline保留作性能参照；M0不是只为重复测Baseline，而是为Baseline表示学习一个随训练更新的边界读出器，并收集此前没有的在线干预数据。

设原任务为 `L_MTDS=L_sup+lambda_MT*L_MSE`。两组的边界头、损失和系数完全相同，唯一机制差别为边界头训练输入是否detach：

\[
\begin{aligned}
M0:&\quad L=L_{MTDS}+\gamma(t)L_b(h(\operatorname{sg}(H)),B),\\
M1:&\quad L=L_{MTDS}+\gamma(t)L_b(h(H),B).
\end{aligned}
\]

**系数预算必须保留：**现有独立头版本是 `0.03*(L_b_half+L_b_full)/2`。去掉full时，为保留half原有的显式系数，建议 `gamma_max=0.015`，前2000步为0，随后2000步ramp。直接用单头0.03会同时将half项权重翻倍。0.015是匹配预算的起点，不是声称它更优；训练后特征和梯度自然会变化，也不意味着实际梯度范数始终相同。

两组应有相同原骨干/边界头初始化、batch顺序与诊断状态策略。新增头/采样独立RNG，诊断不写参数.grad、不更新BN/SGD/EMA。M0须验证不影响原骨干训练轨迹；不能因概念上detach就跳过实现核查。

M0的detach只用于**训练头的反向路径**。评分时，应在当前更新前的同一组头权重上，重新建立 `h(H(g))` 的可导读出，使用 `autograd.grad` 求门梯度，再detach分数；这条诊断图不进入总损失。如果一直detach后才求门梯度，会得到无效归因。

**5. 训练中评分与干预具体检验什么**

对有标签Student使用未乘gamma的边界任务，逐病例计算：

\[
S_c=-\left.\frac{\partial L_b}{\partial g_c}\right|_{g=1}
=-\sum_x\frac{\partial L_b}{\partial H_c(x)}E_{2,c}(x).
\]

这是一阶、条件性的移除贡献，不是通道固有的边界知识量。正值表示小幅弱化预计增大当前loss，负值表示预计减小，近0表示局部不敏感；不对它逐体素取绝对值后仍保留同样解释。

固定诊断时间表，在相同模型状态与相同原始特征上，对单通道/小组执行匹配幅度的弱化。小幅干预检验 `Delta L_b ≈ epsilon * sum(S_c)`；完全移除另作有限幅度压力检查。比较高分、低分和多次随机组，记录：

- 预测与实测变化的相关性、符号一致率、有效梯度比例；
- 高分/随机/低分组的真实loss变化及扰动范数，跨早中晚期和病例分布；
- 经下游decoder重算后，最终分割的边界误差和区域误差是否同向；
- 评分是否仅与激活大小/范数有关，不能以一次高分遮挡成功宣称有效。

梯度分数与干预必须使用同一诊断算子、同一优化步和相同BN/Dropout状态；不能重演旧记录“训练态评分、SGD后eval态遮挡”的状态混合。诊断重算不反向更新模型，参数更新次数仍与原训练一致。

评价时同时记录主输出Dice/HD95/ASD、固定容差的表面指标与前景体积、逐病例失败，以及辅助边界带precision/recall/F1。辅助边界带指标与器官表面指标明确区分。加权BCE输出未必校准，阈值/容差在开跑前固定；现有test在线选模仍只作为开发证据。

进入交互阶段的依据是：多个训练阶段和不同病例中，评分与实际干预有可重复对应，并且不是只对本地辅助头成立。不把相邻时点当作独立种子，也不要求边界辅助监督必须先使两数据集Dice全面超过Baseline。

| 观察 | 下一步 |
|---|---|
| M0评分可靠，M1无收益或损害主任务 | 保留边界读出用于评价，暂不强制其梯度更新骨干 |
| M1改善学习且评分可靠 | 在固定M1设置上继续交互 |
| 只有辅助头敏感，最终分割关系薄弱 | 修订评分目标/路径，暂不加复杂交互 |
| 两组评分均不可靠 | 优先检查读出、目标、分支对应与估计误差；不要用Bank掩盖 |

**6. 第二阶段：验证跨病例传递与选择机制**

先以少量标注病例之间的训练期受控注入检验供体分数与接收方收益是否相关。受检接收方可用其已有GT计算真实变化；不增加训练标注病例，不使用无标签隐藏真值。这个诊断不能替代实际半监督L→U完整训练。

交互模块首版放在Student的E2→D3，采用供体边界内外原型/少量token与受控残差。不同病例空间不对齐，不直接整张复制三维通道图。供体表示与路由stop-gradient；残差投影参数可通过接收方任务学习。

固定M0或M1读出设置后，比以下匹配条件：

| 条件 | 选择依据 | 主要问题 |
|---|---|---|
| 无交互参照 | 已完成M0或M1 | 原训练行为 |
| 随机通道L→U | 随机 | 交互模块/扰动本身是否起作用 |
| 边界贡献L→U | 边界评分 | 是否优于随机 |
| 区域贡献L→U | 原区域任务的相同形式评分 | 边界目标是否提供额外作用 |

各组保持结构、参数初始化、选中数量、幅度、训练损失总预算、前向/状态策略与启用时机匹配。不能只比较“有模块+有边界评分”与裸Baseline。每个条件仍两数据集从头完整训练。

无标签通过原MSE已参与Student学习；L→U使用有标签GT定义供体边界，Teacher提供无标签接收方的预测与可靠性。第一版不额外加无标签边界训练项，也不宣称有标签供体高分自动代表接收方受益。若只从有标签获得通道历史分数并应用于U，应明确它是共享先验，不是U的GT归因。

**7. 第三阶段：按证据加回双向、Memory Bank、多尺度**

- 先验证U→L是否在有效L→U基础上有额外收益。U可能提供分布/语义多样性，但伪边界也可能错误；其价值是待测假设，不由样本量自动保证。Teacher保持未交互目标，反向供体需可靠性过滤。
- EMA分数平滑解决选择随时间抖动；Memory Bank扩大跨batch供体池。二者功能不同，Bank不会自动过滤早期错误，也不会冻结网络中的“好通道”。若使用，优先存边界原型/token及置信度、时间等信息，控制陈旧性；与当前batch供体版本匹配对照。
- 在单尺度机制成立后比较D3、D2、D2+D3。新增尺度匹配总损失/交互预算，不把头数/参数/梯度预算增加都解释为多尺度互补。E4→D1可作为后续位置对照。
- 如要主张DS对机制必要，再做匹配的DS开关实验。现有四尺度DS是Baseline组成；单最终输出也能对多个上游模块求导，多尺度优势需要实验，而非计算图本身保证。
- 最后对保留的关键条件与对应Baseline配套增加种子；正式确认统一采用独立的选模/评价方案。阴性结果也保留，不只补方法种子。

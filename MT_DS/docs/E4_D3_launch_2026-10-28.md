**两条件的实际实现**

| 项目 | E4_legacy_boundary_w003_v1 | D3_boundary_skip_w0015_v1 |
|---|---|---|
| 主任务 | 原MT_DS四尺度CE+Dice、原soft MSE与Teacher | 相同 |
| 边界头输入 | 编码器E4/x4，128ch，1/8 | D3融合特征，32ch，1/2 |
| 头结构 | Conv3(128,32,bias=False)→BN→ReLU→Conv1(32,1) | Conv3(32,32)→ReLU→Conv1(32,1) |
| 边界标签 | 裁剪后GT的3³局部max/min差异 | 完整体积欧氏距离≤2voxel双侧带，池化为half覆盖率 |
| 尺度处理 | logits三线性上采样至full硬标签 | 原生half logits对soft覆盖率 |
| loss | 旧正类加权BCE+Dice，保留旧空边界行为 | 当前独立头的BCE+Dice，排除空边界样本 |
| 系数 | 第1步起0.03 | 前2000步0，随后2000步ramp至0.015 |
| 参数量（辅助头） | 110689 | 27713 |
| 在线分数 | E4 probe输入的绝对梯度乘特征敏感性；另记有符号导数 | D3边界损失对E2→D3 skip门的负梯度 |

D3的0.015保留此前`0.03*(half+full)/2`中half项的显式权重；原四个分割头均保留，暂不使用full辅助边界头。E4与D3同时改变了位置、头结构、目标、尺度处理及时间表，比较的是两个明确方案，不能称为只隔离位置的一项消融。E4只迁移辅助分支，未迁移旧项目的硬伪标签区域训练体系。

两条件都是有标签Student的边界联合监督。没有额外无标签边界优化项、通道交换或Memory Bank。Teacher目标路径保持原样；正常推理不执行辅助头、归因或交互。

**在线诊断的精确定义**

第1步及每200步抽样。诊断发生在主loss反向之后、SGD更新之前，使用本步缓存的编码器特征，临时令decoder/probe为eval且不更新BN、不启用decoder Dropout；诊断结束恢复各模块模式和CPU/CUDA随机状态。该定义是固定编码器条件下的decoder干预，不应宣称为重算整个网络编码路径的总贡献。

- D3只门控E2的skip副本，E2通向更深编码器的路径不改变。用未乘训练系数的边界任务计算`S=-dL_b/dg`。
- E4保留旧`mean(abs(grad*feature))`选择规则；其辅助头敏感性与E4 skip对最终分割的影响分别记录，不能直接改名为下游skip边界贡献。
- 每次选择12.5%通道：E4为16/128、D3为4/32。比较高分、低分及3个独立随机组，分别弱化10%和完全移除；随机组由独立生成器产生。
- 记录原始分数、有符号移除估计、每组实际边界loss/主区域loss/最终分割边界CE/patch Dice/前景比例变化及扰动范数。小幅组相关性只是该轮分组校准描述，不能将几组或相邻训练时点视为独立重复。
- 预热时边界头尚未通过任务学习，记录标记`head_learning_active=false`，不把早期随机读出评分解释为可靠知识。

与主滑窗验证同步，额外在每个评估病例的固定中心patch记录辅助边界带precision/recall/F1和loss。阈值固定0.5，D3先插值logits至full；这些是patch边界带指标，不是全体积器官表面指标，也不用于选模。主评价及Dice-best选模完全沿用历史协议（test在线选模，voxel距离、单向ASD）。

每100步保存自己的完整训练断点。原采样器/worker未增加逐批序列化，续训的逐批精确性仍取决于断点位置与原实现，不能作无条件保证。
